# Mock inventory

The fixture catalog intentionally exceeds the size of one screen:

- 120 Rare Moments
- 180 prompts
- 60 routines
- 36 community circles
- 160 community posts
- 72 journal entries
- 80 mock users
- 220 activity records
- 48 notification plans
- 64 preference records
- 240 sync events
- 24 feature experiments

This makes it possible to test virtualization, sorting, search, filters, pagination, stale content, duplicate IDs, and recovery states without hand-authoring data in each screen.
