# Source basis

This overlay follows the current public repository structure and stated implementation model: Expo Router five-tab app, local-first AsyncStorage state, explicit recommendation feedback, journaling recovery, community circles, Studio routines, profile/scrapbook, privacy-aware AI, and membership/monetization scaffolding.

The overlay is intentionally additive. Existing product behavior should be preserved unless the release pack explicitly adds a guard, fallback, or production capability.
